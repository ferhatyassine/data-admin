# Data Admin Journey

Personal learning portfolio for:
**Administrateur(trice) de l'analyse et de l'intégration des données**
Service de l'imputabilité organisationnelle et des ressources informationnelles — CEPEO

## Focus areas
- Advanced SQL
- Java / JavaScript
- Power BI / Tableau (BI server administration)
- Complex statistical analysis (relational, correlational, predictive)
- Data quality — Ontario Ministry of Education standards
- Aspen + SISOn (school information systems)

## Structure
data-admin/
├── 01-setup/        ← MySQL install, first schema, Day 1 queries
├── 02-sql-basics/   ← SELECT, WHERE, ORDER BY, GROUP BY
├── 03-sql-joins/    ← JOINs, subqueries
├── 04-sql-advanced/ ← CTEs, window functions, stored procedures
├── 05-javascript/   ← JS for data and dashboards
├── 06-python-data/  ← pandas, stats, matplotlib
├── 07-bi-tools/     ← Power BI, Tableau
├── 08-geocoding/    ← maps and spatial data
├── 09-data-quality/ ← governance, Aspen, SISOn
└── 10-project/      ← full CEPEO simulation
